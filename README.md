# 100ANIME-puzzle

Welcome to the **Java Puzzle Game**, a classic sliding tile puzzle with image-based levels — and not just a few... **100 of them** for now we added 3 but people can contribute by adding more assets ! Powered by Swing and built with modularity in mind, this game challenges your brain and gives back nostalgia feeking  while offering a clean, minimal UI. dont forget to give it a try

## 🚀 Features

- 🎮 3x3 sliding tile puzzle
- 🖼️ 100 unique image levels
- 🧠 Intelligent shuffling — always solvable
- ⏱️ Timer and move counter per level
- 🔁 Level reset & next level buttons
- 🧱 Fallback numbered puzzle if an image is missing
